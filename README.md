# Ароматека (web_aroma)

Сайт со статьями об эфирных маслах. Собирается генератором [Eleventy](https://www.11ty.dev/) и публикуется на GitHub Pages автоматически при каждом push в ветку `main`.

## Как добавить статью

1. Скопируйте [templates/new-article.md](templates/new-article.md) в папку [src/stati/](src/stati/).
2. Назовите файл латиницей, например `rozmarin.md`. Статья будет доступна по адресу `/stati/rozmarin/`.
3. Заполните поля в начале файла (между `---`) и напишите текст в формате Markdown.
4. Уберите строку `draft: true`, когда статья готова к публикации.
5. Отправьте изменения на GitHub (`git add`, `git commit`, `git push`). Через минуту-две сайт обновится.

### Поля статьи

| Поле | Обязательно | Что это |
|---|---|---|
| `title` | да | Заголовок статьи |
| `description` | желательно | Короткое описание для карточки и поисковиков |
| `date` | да | Дата публикации, `ГГГГ-ММ-ДД` |
| `note` | желательно | `верхняя`, `средняя` или `базовая`: определяет ярус пирамиды и цвет |
| `oil`, `latin` | нет | Название масла по-русски и по-латыни |
| `part`, `method`, `origin`, `aroma` | нет | Строки «паспорта масла» в шапке статьи |
| `image`, `imageAlt`, `imageCaption` | нет | Картинка в начале статьи (файл кладите в `src/assets/images/`) |
| `draft` | нет | `true`: статья видна только при локальном просмотре |

## Локальный просмотр

Нужен [Node.js](https://nodejs.org/) 18 или новее.

```bash
npm install      # один раз
npm start        # сайт откроется на http://localhost:8080 и будет обновляться при сохранении
```

## Первая публикация на GitHub Pages

1. Создайте на GitHub репозиторий `web_aroma` и отправьте в него проект:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/web_aroma.git
   git add .
   git commit -m "Первая версия сайта"
   git push -u origin main
   ```
2. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
3. Дождитесь окончания сборки на вкладке **Actions**. Сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/web_aroma/`.

Префикс `/web_aroma/` в ссылках сборка подставляет сама, поэтому в статьях ссылки на другие страницы пишутся от корня: `/stati/lavanda/`, `/assets/images/foto.jpg`.

## Структура

```
src/
  stati/            статьи (по одному .md-файлу на статью)
  _data/notes.json  названия и описания нот
  _data/site.json   название и описание сайта
  _includes/        шаблоны страниц
  assets/           стили, скрипты, картинки
  about.md          страница «О сайте»
templates/          шаблон новой статьи (на сайт не попадает)
.github/workflows/  автоматическая публикация
```
